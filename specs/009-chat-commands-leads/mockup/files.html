"""The cart: lines of products, kept in cart.json."""
import json
from pathlib import Path
CART = Path("cart.json")
def load():
if not CART.exists():
return {}
try:
return json.loads(CART.read_text())
except json.JSONDecodeError:
raise SystemExit("cart.json is not valid; it was left as it is.")
def total(cart, catalog):
return sum(catalog[name] * n for name, n in cart.items())

Place B · a feature's loop page (and spec session)

A Files drawer for what this feature's agents are building

On a loop page you mostly want to see what the agents changed. A Files button in the header opens a drawer in place of the side column. It shows this feature's branch, changed files first, each with who changed it and in which task. The list is narrow; opening a file widens the drawer over the agent cards and the feed (B2), so code is read at full width while the header, its buttons and the task tree stay in view. "Open full" goes to Place A with this file and version chosen. The spec session gets the same drawer, next to its documents.

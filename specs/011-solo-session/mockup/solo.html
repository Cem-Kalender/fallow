The project page with solo sessions (revised after the decisions of 2026-11-02). The left column and the top bar stay as they are. The middle column gets two tabs: Plan with the lead and Code with the assistant. Each solo session works in its own worktree, on its own branch started from your branch, so several can be open at once; your project folder is not touched. Fallow commits every turn on the session's branch, so a turn can be undone. Merging, pushing or opening a pull request: you ask the assistant, and Fallow shows what it sees happen to your branches.

2 · Code with the assistant

The assistant's tab opens a list of sessions; each turn its own commit, with "Undo this turn"; a screenshot, the web, a message waiting

Clicking Code with the assistant (shown open here) lists the project's solo sessions: the open one ticked, each named after its first message (renamed in its header), a dot while its assistant works, the number of its changes; + New session starts one from your branch as it is now. Picking one opens it; the tab then shows that session. The header names the session's branch and where it started. In the conversation: a pasted screenshot goes to the assistant with the message; its work shows as in a loop, also what it looks up on the web; under each turn, what it changed and Undo this turn. A message typed while it works waits above the box and is sent when the turn ends.

Five details

The tab names. "Plan with the lead" and "Code with the assistant" say what each is for. Shorter: "Lead" and "Assistant".
A session's end. A session stays in the row until you close it; closing removes its worktree, and its branch too once it is merged (asked first when it is not). Its conversation stays readable.
Setup in a new worktree. A fresh worktree has no installed dependencies (node_modules, a virtual environment). First version: the assistant installs them when asked. Later: a setup command per project that Fallow runs when a session starts.
A file beside the lead too? Today a file opened on the project page takes the chat's place. With the conversation beside the file (view 4), the lead's tab could do the same, so both tabs behave alike.
The top bar's lead picker. "lead ▾" next to "+ New feature" stays the lead's: it picks who leads a new feature. The assistant is picked when a session starts.
